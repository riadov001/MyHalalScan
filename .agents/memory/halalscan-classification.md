## Rule

The following groups are classified as **HARAM** (not WARNING):

- **Emulsifiers**: E471, E472a–f, E473, E474, E475, E476, E477, E478, E479b
- **Glycerine/Glycerol**: E422, glycerine, glycerol, monostéarate de glycérine, distéarate de glycérine, glyceryl monostearate
- **Triacetine**: E1518, triacetin
- **Fatty acids**: E570 (stearic acid), E470a, E470b, stearate, esters d'acides gras
- **Collagen & hydrolysed gelatin**: collagène, collagen, peptides de collagène, gélatine hydrolysée, hydrolyzed gelatin
- **New pork derivatives**: enzymes porcines, extrait de porc

Still **WARNING** (not HARAM):
- Bovine gelatin (requires halal slaughter — unverifiable, but not definitively haram)
- Fish gelatin (most scholars allow — debated)
- E920 L-cysteine, E120 carmine, E904 shellac, rennet/présure, natural flavours, whey/casein, tallow

**Why:** User explicitly requested this reclassification. These ingredients (E471 etc.) are commonly derived from animal fat of unknown origin (often pork in Europe) and are treated as haram by default unless certified halal.

**How to apply:** When adding new E-codes or ingredients to any list, default to HARAM if animal-derived without certification. Only use WARNING when the ingredient *could* be halal but is unverifiable (bovine gelatin, fish gelatin, natural flavours).

**User-editable:** The user wants to be able to modify the default lists from the Settings screen. This is planned for Task #5. The defaults above are the hardcoded baseline.
